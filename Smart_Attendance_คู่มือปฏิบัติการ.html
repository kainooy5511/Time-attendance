หมวดที่ 1: ภาพรวมระบบและฟีเจอร์เด่น (System Overview & Key Features)

1.1 วัตถุประสงค์และประโยชน์ของระบบ

ระบบ Smart Attendance v5.0 ได้รับการออกแบบและพัฒนาขึ้นเพื่อแก้ปัญหาการลงเวลาทำงานแบบเดิม (เช่น การสแกนนิ้วมือที่ต้องสัมผัสร่วมกัน, การตอกบัตรที่ฝากกันตอกได้, หรือเครื่องสแกนราคาแพงที่เชื่อมต่อข้อมูลยาก):

  1. ป้องกันการลงเวลาแทนกัน 100% (Zero Proxy Punch): ใช้โมเดลปัญญาประดิษฐ์ตรวจจับและสกัดเวกเตอร์โครงสร้างใบหน้า 128 มิติ พร้อมบันทึกภาพถ่าย Snapshot เข้าสู่ระบบ Google Drive ทันที
  2. ป้องกันการเช็คอินนอกสถานที่ (Zero GPS Spoofing): ระบบตรวจสอบพิกัด Geolocation ด้วยสูตร Haversine หากอยู่นอกรัศมีที่บริษัทกำหนด (Allowed Radius) ระบบจะล็อกไม่ให้สแกน
  3. โครงสร้าง Serverless ไร้ค่าใช้จ่ายเซิร์ฟเวอร์ (Zero Hosting Cost): ใช้งาน Frontend Static บน Netlify คู่กับ Backend Google Apps Script และฐานข้อมูล Google Sheets ไม่ต้องเช่า Cloud Server รายเดือน
  4. ความปลอดภัยของข้อมูลส่วนบุคคล (Privacy & Access Control): พนักงานแต่ละคนมีรหัส PIN 4 หลักเพื่อเข้าดูประวัติเฉพาะตนเอง ส่วนฝ่ายบุคคลมี Admin PIN เพื่อเข้าถึงเมนูลงทะเบียนและแก้ไขข้อมูล

1.2 ตารางสรุปฟีเจอร์หลัก 8 ประการ

ลำดับ ฟีเจอร์หลัก รายละเอียดความสามารถ ประโยชน์ต่อองค์กร
1 Face Recognition AI ใช้โมเดล SSD MobileNetV1 ตรวจจับตำแหน่งใบหน้า และ FaceNet สกัดเวกเตอร์ 128D (Threshold 0.45) ระบุตัวตนได้แม่นยำภายใน 500ms ป้องกันการทุจริต
2 GPS Geofencing ตรวจสอบพิกัดละติจูด/ลองจิจูดของผู้ใช้งานเทียบกับจุดพิกัดบริษัทแบบเรียลไทม์ บังคับให้พนักงานต้องอยู่ในพื้นที่บริษัทจริงเท่านั้น
3 PWA Mobile-First รองรับ Progressive Web App ติดตั้งเป็นไอคอนบนมือถือได้ทั้ง iOS และ Android ใช้งานสะดวกเหมือนแอปพลิเคชันจริง ไม่ต้องโหลดผ่านสโตร์
4 Google Drive Vault แปลงภาพใบหน้าขณะสแกนเป็นไฟล์ JPEG อัปโหลดเข้าโฟลเดอร์ Attendance_Snapshots มีหลักฐานภาพถ่ายยืนยันทุกครั้งที่เข้างาน
5 OT & Shift Engine คำนวณสถานะ "ตรงเวลา", "มาสาย" และนับชั่วโมงการทำงานล่วงเวลา (OT) อัตโนมัติ ลดภาระงานคำนวณเวลาของฝ่ายบุคคล (HR)
6 Genuine Excel Export ฝังไลบรารี SheetJS ส่งออกประวัติเข้างานเป็นไฟล์ .xlsx แท้พร้อมฟอร์แมตวันที่ สามารถนำข้อมูลไปประมวลผลต่อใน Excel / Payroll ได้ทันที
7 PIN Gate Security ระบบล็อกหน้าประวัติด้วย PIN พนักงาน 4 หลัก และล็อกหน้า Admin ด้วยรหัสผ่าน Admin รักษาความลับข้อมูลเงินเดือนและเวลาทำงานตามกฎหมาย PDPA
8 Auto Data Hygiene ฟังก์ชัน cleanEmptyRows และ cleanMockupData ทำความสะอาดชีตอัตโนมัติ ป้องกันตารางกระโดดข้ามแถวและลบข้อมูลขยะอัตโนมัติ

1.3 โครงสร้างเทคโนโลยี (Tech Stack Architecture)

[Client / Mobile Browser] │ ├── Progressive Web App (PWA) + Service Worker (sw.js) ├── UI: HTML5, CSS3 Glassmorphism, Google Sarabun Font ├── AI: face-api.js v0.22.2 (TensorFlow.js WebAssembly / WebGL) ├── Location: W3C Geolocation API (Haversine Distance Check) └── Export: SheetJS v0.18.5 (.xlsx Full Engine) │ ▼ (HTTPS REST / JSON API) [Google Apps Script Web App - code.gs V5] │ ├── doGet(e) : getConfig, getKnownFaces, getAttendance, cleanEmptyRows └── doPost(e) : registerUser, logAttendance, saveConfig, deleteAttendance, updateAttendance │ ├───▶ [Google Sheets Database] : Users, Attendance, Config └───▶ [Google Drive Storage] : Attendance_Snapshots/ (รูปถ่ายหลักฐาน)

2.2 ลำดับการทำงานขณะสแกนลงเวลา (Sequence Timeline)

1. พนักงานเปิดหน้า scan.html -> ระบบดึง Config และข้อมูลพนักงาน (getKnownFaces) จาก Google Sheets 2. ระบบอ่านพิกัด Geolocation จากมือถือ -> คำนวณระยะห่างด้วยสูตร Haversine - หากอยู่นอกรัศมี: แสดงกล่องเตือนสีแดง และระงับการเปิดกล้อง - หากอยู่ในรัศมี: แสดงสถานะ "อยู่ในพื้นที่บริษัท" และเปิดกล้องอัตโนมัติ 3. พนักงานส่องหน้าเข้าหากล้อง -> AI (face-api.js) ตรวจจับใบหน้าและเทียบเวกเตอร์ 128 มิติ 4. เมื่อค่าความคลาดเคลื่อนน้อยกว่า 0.45 -> ยืนยันตัวตนสำเร็จ แสดงชื่อ-นามสกุล 5. พนักงานกดยืนยัน (หรือระบบนับถอยหลัง) -> ส่ง POST ไปยัง code.gs 6. code.gs ถอดรหัสภาพ Base64 เซฟเป็นไฟล์ JPEG ลง Google Drive (Attendance_Snapshots) 7. code.gs บันทึกข้อมูล (รหัส, ชื่อ, เวลา, วันที่, สถานะปกติ/สาย, ชั่วโมง OT, พิกัด, ลิงก์รูป) ลง Google Sheets 8. หน้าจอแสดงผล "บันทึกสำเร็จ" พร้อมส่งเสียงแจ้งเตือน

หมวดที่ 3: คู่มือการใช้งานสำหรับพนักงานทั่วไป (Staff User Guide)

3.1 การติดตั้งแอปพลิเคชันลงบนหน้าจอมือถือ (PWA Installation)

เพื่อให้ใช้งานสะดวก รวดเร็ว และไม่ต้องพิมพ์ URL ซ้ำๆ พนักงานสามารถติดตั้งระบบเป็นแอปบนมือถือได้ทันที:

  • สำหรับ iPhone / iPad (iOS Safari):
    เปิด Safari ไปที่ลิงก์ระบบ -> กดปุ่ม [แชร์ (Share)] ด้านล่าง -> เลือก [เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)] -> กดปุ่ม [เพิ่ม (Add)]
  • สำหรับ Android (Google Chrome):
    เปิด Chrome เข้าลิงก์ระบบ -> กดจุด 3 จุด (⋮) มุมขวาบน -> เลือก [ติดตั้งแอป (Install App)] หรือ [เพิ่มลงในหน้าจอหลัก]

3.2 ขั้นตอนการสแกนใบหน้าเข้า-ออกงาน (Scan Attendance)

  1. เปิดแอป "ลงเวลา" จากหน้าจอมือถือ -> เข้าสู่หน้าหลัก (index.html)
  2. กดเลือกการ์ดขนาดใหญ่ด้านบน "สแกนใบหน้าลงเวลา (Face Scan Attendance)" (scan.html)
  3. ระบบตรวจสอบตำแหน่ง GPS อัตโนมัติ: หากขึ้นแถบสีเขียว "อยู่ในพื้นที่บริษัท" กล้องจะเปิดทันที
  4. เลือกประเภทงาน: เข้างาน / ออกงาน / เข้างาน OT / ออกงาน OT
  5. ส่องใบหน้าให้ตรงกับกรอบสีเขียวบนหน้าจอในระยะ 40 – 60 ซม. (ถอดแว่นกันแดด/แมสก์ชั่วคราว)
  6. เมื่อระบบตรวจพบใบหน้าตรงกัน จะแสดงชื่อ-นามสกุล -> กดปุ่ม "ยืนยันเข้างาน" (หรือรอระบบนับถอยหลัง)
  7. เมื่อขึ้นข้อความสีเขียว "บันทึกสำเร็จ" เป็นอันเสร็จสิ้นขั้นตอน

3.3 การตรวจสอบประวัติการลงเวลาส่วนบุคคลด้วยรหัส PIN

  1. จากหน้าหลัก กดเลือกเมนู "ประวัติบันทึกเวลา" (history.html)
  2. กรอก "รหัส PIN 4 หลักประจำตัว" ที่ได้รับตอนลงทะเบียน
  3. ระบบจะกรองและแสดงผล เฉพาะรายการลงเวลาของตัวพนักงานเองเท่านั้น โดยไม่แสดงข้อมูลของผู้อื่น เพื่อความเป็นส่วนตัวสูงสุด

หมวดที่ 4: คู่มือสำหรับฝ่ายบุคคลและผู้ดูแลระบบ (HR & Admin SOP)

4.1 การเข้าสู่ระบบด้วย Admin PIN

ข้อกำหนดความปลอดภัยสำหรับฝ่ายบุคคล:
เมนูของผู้ดูแลระบบ (Admin) ทั้งหน้าลงทะเบียนพนักงาน (register.html), หน้าตั้งค่าระบบ (config.html), และการแก้ไข/ลบข้อมูล จะต้องใช้ Admin PIN (รหัสเริ่มต้น: 1234) เพื่อปลดล็อกทุกครั้ง

4.2 การลงทะเบียนพนักงานและบันทึกใบหน้าใหม่ (register.html)

  1. เข้าหน้า "ลงทะเบียนพนักงาน" และกรอก Admin PIN
  2. กรอกข้อมูล: รหัสพนักงาน (Emp ID), รหัส PIN 4 หลักของพนักงาน, ระดับสิทธิ์ (Role), แผนก, และ ชื่อ-นามสกุล
  3. ให้พนักงานยืนส่องหน้าตรงกับกล้องในที่สว่าง
  4. เมื่อระบบตรวจจับใบหน้าได้ ปุ่ม "ถ่ายภาพและบันทึกใบหน้า" จะเปลี่ยนเป็นสีน้ำเงินพร้อมกด
  5. กดปุ่มบันทึก 1 ครั้ง -> ระบบจะคำนวณเวกเตอร์ 128 มิติ และส่งไปจัดเก็บลงชีต Users ทันที

4.3 การตั้งค่าพิกัด GPS รัศมี และเวลางาน (config.html)

  • จุดเช็คอิน GPS: หากยืนอยู่ที่ออฟฟิศ ให้กดปุ่ม "ดึงตำแหน่งปัจจุบัน (Get Current Location)" ระบบจะดึงพิกัดจริงมาใส่ในช่อง Lat/Lng ทันที
  • รัศมีที่ยอมรับ (Allowed Radius): แนะนำตั้งที่ 0.1 (100 เมตร) หรือ 0.05 (50 เมตร) สำหรับตึกสำนักงาน (หากใส่ 0 คือปิดตรวจ GPS)
  • เวลาเริ่มงานปกติ: เช่น 08:30 (สแกนหลังเวลานี้จะขึ้นสถานะ "สาย")
  • เวลาเริ่มคิด OT: เช่น 17:00 (ระบบจะคำนวณชั่วโมง OT อัตโนมัติเมื่อออกงานหลัง 17:00)
  • เปลี่ยน Admin PIN: กรอกรหัสใหม่ในช่อง Admin PIN แล้วกดบันทึก

4.4 การตรวจสอบรายงาน คัดกรอง และดูรูปถ่ายหลักฐาน (history.html)

ผู้ดูแลระบบสามารถกรอก Admin PIN ในหน้า history.html เพื่อดูข้อมูลพนักงานทุกคน คัดกรองตามวันที่ แผนก หรือสถานะ พร้อมคลิกดูรูปถ่าย Snapshot และเปิดพิกัดจริงบน Google Maps ได้ทุกรายการ

4.5 การแก้ไขและลบรายการลงเวลา (Edit/Delete Attendance)

  • แก้ไขเวลา/สถานะ: คลิกปุ่ม [แก้ไข] ที่รายการ -> ปรับเปลี่ยนเวลา ประเภท หรือชั่วโมง OT -> กดยืนยัน ข้อมูลใน Google Sheets จะอัปเดตทันที
  • ลบรายการ: คลิกปุ่ม [ลบ] เพื่อตัดรายการที่พนักงานกดซ้ำซ้อนทิ้ง

4.6 การส่งออกรายงานเป็นไฟล์ Excel (.xlsx)

คลิกปุ่มสีเขียว "ส่งออก Excel (.xlsx)" ในหน้า history.html ระบบจะสร้างไฟล์ Excel แท้พร้อมฟอร์แมตวันที่ ดาวน์โหลดลงเครื่องคอมพิวเตอร์พร้อมนำเข้าโปรแกรมเงินเดือนได้ทันที

4.7 เครื่องมือทำความสะอาดฐานข้อมูล (Database Housekeeping)

  • ลบแถวว่างในชีต (Clean Empty Rows): สแกนและลบแถวว่างในชีต Attendance ให้ตารางชิดติดกัน ไม่เกิดปัญหาตารางกระโดดข้ามแถว
  • ล้างข้อมูลทดสอบ (Clean Mockup Data): ล้างข้อมูลจำลองช่วงติดตั้งระบบ คงเหลือเฉพาะข้อมูลจริงที่พร้อมใช้งาน 100%

5.2 สูตรคำนวณระยะพิกัด GPS (Haversine Formula)

function getDistanceFromLatLonInKm(lat1, lon1, lat2, lon2) {
  var R = 6371; // รัศมีโลกเฉลี่ย (กิโลเมตร)
  var dLat = deg2rad(lat2 - lat1);
  var dLon = deg2rad(lon2 - lon1);
  var a = Math.sin(dLat/2) * Math.sin(dLat/2) +
          Math.cos(deg2rad(lat1)) * Math.cos(deg2rad(lat2)) * 
          Math.sin(dLon/2) * Math.sin(dLon/2);
  var c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c; // ระยะทางจริงในหน่วยกิโลเมตร
}

หมวดที่ 7: การแก้ไขปัญหาและคำถามที่พบบ่อย (Troubleshooting & FAQ)

ปัญหาที่พบ สาเหตุที่เป็นไปได้ วิธีการแก้ไข
กล้องไม่ยอมเปิด / จอดำ เบราว์เซอร์ยังไม่ได้รับอนุญาตให้ใช้กล้อง หรือไม่ได้เข้าผ่าน HTTPS • ตรวจสอบว่าเข้าด้วย URL https://
• กดรูปแม่กุญแจหน้า URL แล้วเลือก "อนุญาตการใช้กล้อง"
เตือน "อยู่นอกพื้นที่" พิกัด GPS ผู้ใช้คลาดเคลื่อน หรืออยู่นอกรัศมี • ตรวจสอบว่าเปิด Location Service ในมือถือแล้ว
• ให้ Admin เข้าหน้า config.html ขยายรัศมีเป็น 0.2 หรือ 0.5 กม.
กล้องสแกนไม่ติด / ไม่ขึ้นชื่อ แสงสว่างไม่พอ หรือใบหน้าเอียงเกินไป • ขยับเข้าหาบริเวณที่มีแสงสว่าง ส่องหน้าตรงกับกล้อง
• ให้ Admin ช่วยลงทะเบียนใบหน้าซ้ำในหน้า register.html
ขึ้น "เชื่อมต่อ API ไม่ได้" URL ของ Google Apps Script ไม่ถูกต้อง หรือยังไม่ได้เปิดเป็น Anyone • ตรวจสอบไฟล์ js/api-config.js
• ตรวจสอบใน Apps Script ว่าสิทธิ์ Access ตั้งเป็น Anyone แล้วหรือไม่
